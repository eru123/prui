Theming

One set of CSS-variable tokens carries every prui component. Apps override tokens, not component source. The t4xlabs multi-theme pass, productized.

Token reference

--brand7c9cff
--brand-2ff7c9c
--ok3ddc97
--warnffc15e
--bg000000
--surface0f0f10
--raise1a1a1c
--line2a2a2e

Usage

brand.css
/* your app, not prui source */
:root {
  --brand: #e5673f;      /* warm t4xlabs-style brand */
  --bg: #0c0b09;
  --surface: #15130f;
}
/* every prui component now renders in your brand.
   no component file is touched. */
