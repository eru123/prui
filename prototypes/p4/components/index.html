Button

Triggers an action or event. The one component every app in the fleet renders, unified from four nearly-identical copies.

Live

button / variants + sizesreact 19
v1.2.0

Usage

dashboard.tsx
import { Button } from '@skiddph/prui'

export function SaveBar() {
  return (
    <Button variant="primary" size="md" onClick={save}>
      Save changes
    </Button>
  )
}

Props

PropTypeDefaultDescription
variant'primary' | 'default' | 'ghost' | 'danger''default'Visual weight. primary carries the accent gradient.
size'sm' | 'md' | 'lg''md'Height and padding scale.
asChildbooleanfalseMerge props onto the child element instead of rendering a button. Unified from the icanhelp fork.
loadingbooleanfalseShows a spinner and disables interaction.
onClick() => void-Fires on activate (click or keyboard Space/Enter).
The asChild prop is the reason this component exists twice in production today. HRLabs ships without it, icanhelp ships with it; prui ships the superset.
