AppShell

Sidebar, header, and content area driven by one nav config object. Collapsible sections, active-route highlighting, and theming come built in.

Live

You are inside the AppShell right now. This documentation site renders with the layout it documents.
app-shell / nav config previewreact 19
SlotWhat rendersDriven by
sidebarGrouped nav, collapsible groups, active-route highlightnav config
headerSearch, theme toggle, notifications, avatar menuheader slots
contentYour routes; centered max-width column by defaultchildren

Usage

app.tsx
import { AppShell } from '@skiddph/prui/shell'

const nav = [
  { group: 'Docs', items: [
    { name: 'Introduction', href: '/', icon: Home },
    { name: 'Components', href: '/components', icon: Search },
  ]},
  { group: 'System', items: [
    { name: 'Theming', href: '/theming', icon: Theme },
  ]},
]

export function App() {
  return (
    <AppShell nav={nav} header={<SearchBar />}>
      {routes}
    </AppShell>
  )
}
