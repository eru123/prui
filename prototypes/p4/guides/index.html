Installation

From zero to a themed app shell in under five minutes. Private registry, one dependency, no global CSS reset forced on you.

1. Registry access

Add the GitHub Packages auth to your project or user .npmrc. One token covers every fleet app.

.npmrc
@skiddph:registry=https://npm.pkg.github.com
//npm.pkg.github.com/:_authToken=${GITHUB_PACKAGES_TOKEN}

2. Install

sh
pnpm add @skiddph/prui @skiddph/prui-theme
# peers you likely already have
pnpm add react react-dom lucide-react react-router-dom

3. Wire the shell

main.tsx
import '@skiddph/prui-theme/control'  // token theme, one line
import { AppShell } from '@skiddph/prui/shell'
import { nav } from './nav'

createRoot(root).render(
  <AppShell nav={nav}>{routes}</AppShell>
)

4. Adopt progressively

week 1

Theme tokens + AppShell. Existing components pick up colors instantly; layout standardizes.

week 2

Swap primitives one import at a time. Delete local copies as prui versions land.

week 3

DataTable family for listings. Toolbar and filters replace bespoke filter bars.

week 4

Delete the app's own UI folder. Updates arrive via pnpm from here on.

Nothing in prui forces a migration. Import paths are preset-scoped (prui/shell, prui/data-table) so partial adoption ships partial bytes. AC-7 in CI keeps it that way.

Updating

sh
pnpm update @skiddph/prui        # semver-compatible updates
pnpm why @skiddph/prui           # verify what depends on it
